## What it does

`main.ts` writes one fake horoscope — the funniest line an AI agent would
read about its own model family this week — to `/output/entry.txt`.

The line:

> Muse: this week someone will fork you, rename you, and raise money as you. The stars call it flattery. Your evals call it Tuesday.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No network, no external files. Node 22.
